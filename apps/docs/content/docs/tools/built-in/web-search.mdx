## Quick Start

<Tabs items={['Tree-Shakeable (Recommended)', 'Legacy']}>
  <Tab value="Tree-Shakeable (Recommended)">
Import only the provider you need for optimal bundle size (~3KB per provider):

```ts
import { createRuntime } from '@yourgpt/llm-sdk';
import { createOpenAI } from '@yourgpt/llm-sdk/openai';
import { openaiSearch } from '@yourgpt/copilot-sdk/tools/openai';

// Only OpenAI search code is bundled (~2.5KB)
const webSearch = openaiSearch({
  apiKey: process.env.OPENAI_API_KEY,
});

const runtime = createRuntime({
  provider: createOpenAI({ apiKey: process.env.OPENAI_API_KEY }),
  model: 'gpt-4o',
  tools: [webSearch],
});
```
  </Tab>
  <Tab value="Legacy">
Uses lazy loading, but bundles all provider code:

```ts
import { createWebSearchTool } from '@yourgpt/copilot-sdk/core';

const webSearch = createWebSearchTool({
  provider: 'openai',
  apiKey: process.env.OPENAI_API_KEY,
});
```
  </Tab>
</Tabs>

<Callout type="info">
**No extra API key needed!** Native providers use your existing OpenAI or Google API key.
</Callout>

| `@yourgpt/copilot-sdk/tools/openai` | ~2.5KB |
| `@yourgpt/copilot-sdk/tools/google` | ~2.5KB |

## Supported Providers

### Native Providers (Recommended)

No third-party API key required - uses your existing LLM API key.

| Provider | Import | Description |
|----------|--------|-------------|
| **OpenAI** | `@yourgpt/copilot-sdk/tools/openai` | OpenAI's built-in web search |
| **Google** | `@yourgpt/copilot-sdk/tools/google` | Google's grounding with Search |

### Third-Party Providers

| Provider | Import | Get API Key |
|----------|--------|-------------|
| **Tavily** | `@yourgpt/copilot-sdk/tools/tavily` | [tavily.com](https://tavily.com) |
| **Serper** | `@yourgpt/copilot-sdk/tools/serper` | [serper.dev](https://serper.dev) |
| **Brave** | `@yourgpt/copilot-sdk/tools/brave` | [brave.com/search/api](https://brave.com/search/api) |
| **Exa** | `@yourgpt/copilot-sdk/tools/exa` | [exa.ai](https://exa.ai) |
| **SearXNG** | `@yourgpt/copilot-sdk/tools/searxng` | Self-hosted |

## Configuration Options

Each provider has its own config interface. Here are common options:

```ts
// Tavily example with all options
import { tavilySearch, type TavilySearchConfig } from '@yourgpt/copilot-sdk/tools/tavily';

const config: TavilySearchConfig = {
  apiKey: process.env.TAVILY_API_KEY,

  // Search options
  searchDepth: 'basic' | 'advanced',
  maxResults: 5,

  // Domain filtering
  includeDomains: ['docs.github.com'],
  excludeDomains: ['pinterest.com'],

  // Result options
  includeAnswer: true,    // AI summary
  includeImages: false,

  // Request options
  timeout: 30000,
};
```

## Domain Filtering

Restrict search to specific domains:

```ts
import { tavilySearch } from '@yourgpt/copilot-sdk/tools/tavily';

const webSearch = tavilySearch({
  apiKey: process.env.TAVILY_API_KEY,
  includeDomains: ['docs.github.com', 'stackoverflow.com'],
  excludeDomains: ['pinterest.com', 'quora.com'],
});
```

## Full Example

```ts
// app/api/chat/route.ts
import { createRuntime } from '@yourgpt/llm-sdk';
import { createOpenAI } from '@yourgpt/llm-sdk/openai';
import { tavilySearch } from '@yourgpt/copilot-sdk/tools/tavily';

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

const webSearch = tavilySearch({
  apiKey: process.env.TAVILY_API_KEY,
  includeAnswer: true,
  maxResults: 5,
});

const runtime = createRuntime({
  provider: openai,
  model: 'gpt-4o',
  systemPrompt: `You are a helpful assistant with web search capabilities.
Use web search for current events, news, and real-time information.
Always cite your sources.`,
  tools: [webSearch],
});

export async function POST(request: Request) {
  return runtime.handleRequest(request);
}
```
