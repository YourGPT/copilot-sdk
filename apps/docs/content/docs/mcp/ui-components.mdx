The SDK includes pre-built React components for displaying MCP connection status and available tools. These components integrate seamlessly with the SDK's styling system.

## MCPPanel

A complete MCP connection management panel that includes status, controls, and tool listing.

```tsx
import { MCPPanel } from '@yourgpt/copilot-sdk/ui';
import { useMCPTools } from '@yourgpt/copilot-sdk/react';

function GitHubConnection() {
  const {
    state,
    connect,
    disconnect,
    refreshTools,
    isLoading,
  } = useMCPTools({
    name: "github",
    transport: "http",
    url: "https://mcp.github.com",
    autoConnect: false, // We'll control connection manually
  });

  return (
    <MCPPanel
      state={state}
      onConnect={connect}
      onDisconnect={disconnect}
      onRefresh={refreshTools}
      isLoading={isLoading}
      title="GitHub"
      showToolSchema={true}
      maxVisibleTools={5}
      collapsible={true}
      defaultCollapsed={false}
    />
  );
}
```

### Props Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `state` | `MCPClientState` | Required | Current MCP client state |
| `onConnect` | `() => void` | - | Connect button callback |
| `onDisconnect` | `() => void` | - | Disconnect button callback |
| `onRefresh` | `() => void` | - | Refresh tools callback |
| `isLoading` | `boolean` | `false` | Show loading state |
| `className` | `string` | - | Additional CSS classes |
| `title` | `string` | `"MCP Server"` | Panel title |
| `showToolSchema` | `boolean` | `false` | Show tool parameter details |
| `maxVisibleTools` | `number` | `5` | Max tools before "show more" |
| `collapsible` | `boolean` | `false` | Allow collapsing the panel |
| `defaultCollapsed` | `boolean` | `false` | Start collapsed |

### Visual States

The panel displays different visual states:

- **Disconnected**: Gray status indicator, shows "Connect" button
- **Connecting**: Pulsing yellow indicator, disabled button with "Connecting..."
- **Connected**: Green indicator, shows server info, tools list, and "Disconnect" button
- **Error**: Red indicator with error message

## MCPStatus

A simple status indicator showing the current connection state.

```tsx
import { MCPStatus } from '@yourgpt/copilot-sdk/ui';

function StatusIndicator() {
  const { state } = useMCPClient(config);

  return (
    <MCPStatus
      state={state.connectionState}
      serverName={state.serverInfo?.name}
      size="md"
      showLabel={true}
    />
  );
}
```

### Props Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `state` | `MCPConnectionState` | Required | Connection state |
| `serverName` | `string` | - | Server name (shown when connected) |
| `className` | `string` | - | Additional CSS classes |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Size variant |
| `showLabel` | `boolean` | `true` | Show text label |

### Status Colors

| State | Color | Label |
|-------|-------|-------|
| `disconnected` | Gray | "Disconnected" |
| `connecting` | Yellow (pulsing) | "Connecting..." |
| `connected` | Green | "Connected to {serverName}" |
| `error` | Red | "Connection Error" |

### Size Variants

```tsx
// Small - compact for headers
<MCPStatus state={state} size="sm" />

// Medium - default size
<MCPStatus state={state} size="md" />

// Large - prominent display
<MCPStatus state={state} size="lg" />
```

## MCPToolList

Displays a list of available MCP tools with their descriptions.

```tsx
import { MCPToolList } from '@yourgpt/copilot-sdk/ui';

function ToolsDisplay() {
  const { state, callTool } = useMCPClient(config);

  return (
    <MCPToolList
      tools={state.tools}
      maxVisible={10}
      showSchema={true}
      onToolClick={(tool) => {
        console.log(`Clicked: ${tool.name}`);
        // Optionally call the tool directly
      }}
      emptyMessage="No tools available"
    />
  );
}
```

### Props Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `tools` | `MCPToolDefinition[]` | Required | List of MCP tools |
| `className` | `string` | - | Additional CSS classes |
| `maxVisible` | `number` | `10` | Max visible before "show more" |
| `showSchema` | `boolean` | `false` | Show parameter details |
| `onToolClick` | `(tool) => void` | - | Tool click handler |
| `emptyMessage` | `string` | `"No tools available"` | Empty state text |

### Features

- **Expandable list**: Shows "Show X more tools..." when exceeding `maxVisible`
- **Parameter details**: When `showSchema={true}`, shows expandable parameter info
- **Required indicators**: Parameters marked with red asterisk (*) are required
- **Click handling**: Optional `onToolClick` for custom interactions

## MCPToolItem

Individual tool item component (used by MCPToolList).

```tsx
import { MCPToolItem } from '@yourgpt/copilot-sdk/ui';

function SingleTool() {
  const tool = {
    name: "create_issue",
    description: "Create a new GitHub issue",
    inputSchema: {
      type: "object",
      properties: {
        title: { type: "string", description: "Issue title" },
        body: { type: "string", description: "Issue body" },
      },
      required: ["title"],
    },
  };

  return (
    <MCPToolItem
      tool={tool}
      showSchema={true}
      onClick={() => console.log("Tool clicked")}
    />
  );
}
```

### Props Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `tool` | `MCPToolDefinition` | Required | Tool definition |
| `showSchema` | `boolean` | `false` | Show parameters |
| `onClick` | `() => void` | - | Click handler |
| `className` | `string` | - | Additional CSS classes |

## Styling Customization

All components use Tailwind CSS classes and integrate with the SDK's theming system. You can customize appearance using:

### CSS Custom Properties

```css
/* Override in your CSS */
:root {
  --primary: 221.2 83.2% 53.3%;
  --secondary: 210 40% 96.1%;
  --muted-foreground: 215.4 16.3% 46.9%;
  --border: 214.3 31.8% 91.4%;
  /* ... other variables */
}
```

### Tailwind Class Overrides

```tsx
<MCPPanel
  className="border-2 border-blue-500 rounded-xl"
  state={state}
/>
```

### Custom Components

For full control, build your own components using the hooks:

```tsx
function CustomMCPDisplay() {
  const { state, isConnected, toolDefinitions } = useMCPTools(config);

  return (
    <div className="my-custom-mcp-panel">
      <div className={`status ${state.connectionState}`} />
      <h3>{state.serverInfo?.name}</h3>
      <ul>
        {state.tools.map(tool => (
          <li key={tool.name}>{tool.name}</li>
        ))}
      </ul>
    </div>
  );
}
```

## Complete Example

Here's a complete example showing all components together:

```tsx
import {
  CopilotProvider,
  useMCPTools,
} from '@yourgpt/copilot-sdk/react';
import {
  CopilotChat,
  MCPPanel,
  MCPStatus,
} from '@yourgpt/copilot-sdk/ui';

function App() {
  return (
    <CopilotProvider runtimeUrl="/api/chat">
      <div className="flex h-screen">
        {/* Sidebar with MCP connections */}
        <aside className="w-80 p-4 border-r space-y-4">
          <h2 className="font-bold">Connections</h2>
          <GitHubConnection />
          <SlackConnection />
        </aside>

        {/* Main chat area */}
        <main className="flex-1">
          <CopilotChat />
        </main>
      </div>
    </CopilotProvider>
  );
}

function GitHubConnection() {
  const mcp = useMCPTools({
    name: "github",
    transport: "http",
    url: "https://mcp.github.com",
    headers: { Authorization: `Bearer ${token}` },
    autoConnect: false,
  });

  return (
    <MCPPanel
      state={mcp.state}
      onConnect={mcp.connect}
      onDisconnect={mcp.disconnect}
      onRefresh={mcp.refreshTools}
      isLoading={mcp.isLoading}
      title="GitHub"
      collapsible
    />
  );
}

function SlackConnection() {
  const mcp = useMCPTools({
    name: "slack",
    transport: "http",
    url: "https://mcp.slack.com",
    autoConnect: false,
  });

  return (
    <MCPPanel
      state={mcp.state}
      onConnect={mcp.connect}
      onDisconnect={mcp.disconnect}
      isLoading={mcp.isLoading}
      title="Slack"
      collapsible
      defaultCollapsed
    />
  );
}
```
