The YourGPT Copilot SDK provides built-in support for the [Model Context Protocol (MCP)](https://modelcontextprotocol.io), enabling your AI copilot to connect to MCP servers and use their tools seamlessly.

## What is MCP?

MCP (Model Context Protocol) is an open standard that allows AI assistants to connect to external tools and data sources. With MCP, your copilot can:

- **Access external services** - GitHub, Slack, databases, APIs
- **Execute local tools** - File systems, code execution, system commands
- **Display interactive UIs** - Forms, charts, product cards via MCP-UI

## Quick Start

The fastest way to get started is with the `useMCPTools` hook, which handles connection management and automatically registers tools with the CopilotProvider.

```tsx
import { CopilotProvider, useMCPTools } from '@yourgpt/copilot-sdk/react';
import { CopilotChat } from '@yourgpt/copilot-sdk/ui';

function App() {
  return (
    <CopilotProvider runtimeUrl="/api/chat">
      <GitHubMCP />
      <CopilotChat />
    </CopilotProvider>
  );
}

function GitHubMCP() {
  const { isConnected, toolDefinitions } = useMCPTools({
    name: "github",
    transport: "http",
    url: "https://mcp.github.com",
    headers: { Authorization: `Bearer ${process.env.GITHUB_TOKEN}` },
    autoConnect: true,
  });

  if (!isConnected) return <div>Connecting to GitHub...</div>;
  return <div>{toolDefinitions.length} GitHub tools available</div>;
}
```

<Callout type="info">
  When tools are registered with `useMCPTools`, they automatically become available to the AI assistant in your chat.
</Callout>

## How It Works

```
┌─────────────────┐      ┌──────────────────┐      ┌─────────────────┐
│                 │      │                  │      │                 │
│   Your App      │─────▶│  MCP Client      │─────▶│  MCP Server     │
│   (React)       │      │  (SDK)           │      │  (Remote/Local) │
│                 │◀─────│                  │◀─────│                 │
└─────────────────┘      └──────────────────┘      └─────────────────┘
        │                        │
        │                        │ Tools are automatically
        │                        │ registered with CopilotProvider
        │                        │
        └────────────────────────┘
```

1. **Connect** - Your app connects to an MCP server using the SDK
2. **Discover** - The SDK fetches available tools from the server
3. **Register** - Tools are automatically registered with CopilotProvider
4. **Use** - The AI assistant can call these tools during conversations

## Supported Features

| Feature | Status | Description |
|---------|--------|-------------|
| HTTP Transport | Supported | Connect to remote MCP servers via HTTP |
| SSE Transport | Supported | Real-time streaming via Server-Sent Events |
| Stdio Transport | Coming Soon | Connect to local MCP servers via stdin/stdout |
| Tool Discovery | Supported | Automatic tool listing and schema parsing |
| Tool Execution | Supported | Call tools and handle results |
| MCP-UI | Supported | Render interactive UI components |
| Elicitation | Supported | Human-in-the-loop approval flows |
| Multi-Server | Supported | Connect to multiple MCP servers simultaneously |

## Transport Types

Choose the transport type based on your MCP server:

<Tabs items={['HTTP (Recommended)', 'SSE', 'Stdio']}>
  <Tab value="HTTP (Recommended)">
    ```typescript
    // For most remote MCP servers
    const config = {
      name: "github",
      transport: "http",
      url: "https://mcp.github.com",
      headers: { Authorization: `Bearer ${token}` },
    };
    ```
    Best for: Remote API-based MCP servers
  </Tab>
  <Tab value="SSE">
    ```typescript
    // For servers that stream responses
    const config = {
      name: "analytics",
      transport: "sse",
      url: "https://mcp.analytics.com/events",
    };
    ```
    Best for: Real-time data streaming
  </Tab>
  <Tab value="Stdio">
    ```typescript
    // For local MCP servers (coming soon)
    const config = {
      name: "filesystem",
      transport: "stdio",
      command: "npx",
      args: ["-y", "@anthropic/filesystem-mcp-server"],
    };
    ```
    Best for: Local tool execution
  </Tab>
</Tabs>
